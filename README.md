# Reproducibility Notes

Because commercial LLMs are stochastic systems, repeated executions may produce slightly different results.

To improve reproducibility:

-   Original experimental outputs are provided.
-   All prompts and inference scripts are included.
-   Analysis scripts are provided.
-   Statistical evaluation procedures are included.

The provided files enable researchers to verify and reproduce the experimental workflow described in the paper.
